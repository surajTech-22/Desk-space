## User-reported issues to hold in acceptance scope
- Search must return **real matching files**, not just folders, across accessible drives; test with PDF, XLSX, DOCX and hidden/permission-limited files on a real device.
- Running Apps/Deck must stay **below its own circle**, scroll when there is inadequate room, never cover the circle, and preserve per-monitor positions. R289 CI geometry tests are synthetic; physical laptop screenshot is required.
- Precision touchpad needs fractional wheel/gesture scrolling in Deck, subdonut and Excel/Information screens without unintended drag or click.
- Two independent physical monitor widgets must not magnetically snap, mirror menu activation, duplicate positional offsets or cross monitor boundaries; held-file data stays shared.
- Update must gracefully close all application Windows/tray, safely handle unsaved work, download, SHA256-check, install, restart, retain data, and verify rollback on a real Windows machine.
- Excel mappings/formulas, correct blank-value handling, guarded table creation and both import/paste routes need real Office COM acceptance; do not infer from synthetic tests.
