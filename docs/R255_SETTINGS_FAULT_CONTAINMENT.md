# R255 — Workspace settings navigation and recoverable tool-launch errors

DeskSpace's Features page previously caught only three classes of errors while opening tools. Other recoverable exceptions thrown by a Settings or Features action could escape the WPF Click handler and potentially close the entire Workspace. R255 adds a small local, synchronous launch guard that catches recoverable exceptions, reports only their type (never paths, filenames, secrets or messages), and leaves the main Workspace interactive. Fatal runtime corruption remains unhandled. It also links the existing Settings tab from Features without constructing another settings store.

The guard does not change existing tool state, clipboard content, credentials, Excel data or update channels. Native Windows tests verify normal operation, recoverable settings exceptions with private error text redacted, subsequent successful operations, and propagation of synthetic fatal exceptions. This is scoped to Features-initiated settings and tool launches; it does **not** claim all standalone widget Settings dialogs are crash-proof. Real installed-PC Settings acceptance is still required before release.
